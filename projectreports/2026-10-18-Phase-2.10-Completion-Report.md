## 6. Known deviations and findings

- **R7 preview:** the previewed page's own primary button still renders filled.
  It is inert and cannot be clicked. Plan §3.5 asked for it to be de-emphasised.
- **R7 highlights:** these use the CSS Custom Highlight API. Browsers without it
  show the pages unmarked; the caption still says what came from the file.
- **Import wizard:** its sticky action bar covers the assistant launcher while a
  wizard step is on screen. This was deliberate (plan §3.4).
- **Finding outside scope, not fixed.** On the asset directory (and other
  pages), buttons that pass their icon as a child render the icon above the
  label: `Button` wraps children in a span, so `leftIcon` is the working
  pattern. The new Import link uses `leftIcon`; the pre-existing Export and
  Add buttons were left as they were.
