## 1. Pipeline commands executed

```bash
cd docs && python build_publication_sources.py      # stage 1
cd docs && python build_word_deliverables.py        # stage 2
```

**One deviation from the literal instruction, and why.** The task specified
`python docs/build_publication_sources.py`. Both scripts resolve every path
relative to the **current working directory**, not to the script's own location:
stage 1 opens `"Software Design Description.md"` and writes to `"_publish"`,
stage 2 reads `PUB = "_publish"` and writes to `OUT = "../deliverables/word"`.
Neither calls `chdir`, and neither uses `__file__`. Run from the repository
root, stage 1 fails immediately on a missing file. They were therefore invoked
as the same commands with `docs/` as the working directory — the pipeline's
actual contract. The scripts' own docstrings say "Run: python
docs/build_publication_sources.py", which is inaccurate; that is a pre-existing
documentation defect in the scripts, reported here and **not fixed**, since
application and tooling files were out of scope.

Stage 2 was run only after stage 1's output was verified (§2). Neither stage was
skipped.

**Environment:** pandoc 3.9 via pypandoc, python-docx, PIL, Node v20.20.2 with
npx 10.8.2 for `@mermaid-js/mermaid-cli`.
