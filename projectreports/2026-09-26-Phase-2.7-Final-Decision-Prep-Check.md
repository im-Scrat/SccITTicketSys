### 6.1 Precisely what these artifacts protect

1. **They give `rollback-prod.sh` a resolvable target.** Without the manifest the
   script falls to its *"no manifest — rolling back the images only"* branch.
2. **They re-arm the schema-ahead guard.** This is the substantive protection.
   The guard is conditional on the manifest supplying `migration_count`:

   ```sh
   if [ -n "$TARGET_MIGRATIONS" ] && [ "$LIVE_MIGRATIONS" -gt "$TARGET_MIGRATIONS" ]; then
       warn "the live schema is AHEAD of the target release by …"
   ```

   Without it, rolling a **30-migration image** back against a **32-migration
   database** would proceed **with no warning at all**. With it restored, the
   plan step now prints `30 expected by the target release`.
3. **They restore the rollback hint in `deploy-prod.sh`.** On smoke-test failure
   the script prints a concrete rollback command only when `releases/current`
   supplies a previous release; otherwise it prints nothing.
