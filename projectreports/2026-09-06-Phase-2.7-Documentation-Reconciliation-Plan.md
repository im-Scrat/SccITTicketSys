## 3. Blocking contradiction — FR-NOT-003 trigger count

The authorization states **"FR-NOT-003 has 10 of 12 triggers implemented"**,
carried from the WP-2.7a register. **That figure cannot be reproduced against
the code**, and CLAUDE.md §2 puts the repository above any report.

### What FR-NOT-003 actually enumerates

The requirement lists **twelve** semicolon-separated trigger clauses:

| # | Clause | State |
|---:|---|---|
| 1 | ticket assigned / reassigned | ✅ implemented |
| 2 | ticket status change | ✅ implemented |
| 3 | new comment on a followed/owned ticket | ✅ implemented |
| 4 | SLA breach / nearing breach | ✅ implemented |
| 5 | maintenance scheduled / due | ✅ implemented |
| 6 | maintenance rescheduled | ✅ implemented |
| 7 | low-stock reorder | ❌ **T7 — WP-2.4b** |
| 8 | procurement approval / rejection | ❌ **T8 — WP-2.4b** |
| 9 | work support request submitted | ✅ implemented |
| 10 | Administrator decision on that request | ✅ implemented |
| 11 | account lockout | ✅ implemented |
| 12 | new announcements | ❌ **T12 — WP-2.7c** |

**Nine of twelve clauses are implemented. Three are not.**

### Verified in source, not inferred

- `backend/app/Enums/NotificationTopic.php` — **11 cases**, no low-stock,
  procurement or announcement topic.
- `backend/app/Domains/Administration/Listeners/` — **9 listeners**; T11 is
  wired through `AuthService` rather than a listener.
- A unit test already asserts that **no topic and no event class exists for T7
  or T8**, so the gap cannot close silently.

### Why the report said "ten"

The WP-2.7a report names only **T7 and T8** as unsatisfied, while listing
**T12 separately as WP-2.7c work** — so the ratio omits one unimplemented
clause. At topic granularity the figure is **11 of 14**; at clause granularity
**9 of 12**. Neither arithmetic yields ten of twelve.

### The decision required

| Option | Text to be written | Assessment |
|---|---|---|
| **A** | "**nine of twelve**; T7/T8 carried to WP-2.4b, T12 to WP-2.7c" | Matches the code. **Recommended.** |
| **B** | Keep "ten of twelve" | Preserves continuity with the WP-2.7a report, but records a number the repository contradicts |
| **C** | Drop the ratio; enumerate implemented vs outstanding | Unambiguous and cannot drift as triggers land. **Also recommended.** |

**S1 and the SRS revision-history entry are blocked on this answer.** Every
other amendment in this plan is unaffected and can proceed independently.
